# OW POV Switcher

Overwatchの試合動画を、視点ごとに切り替えて確認するためのプレイヤーです。

試合カタログから見たい試合を選び、同じ場面を別のプレイヤー視点から確認できます。ゲーム内リプレイを見返すように、試合全体の流れやプレイヤー同士の位置関係を確認する用途を想定しています。

## ページ

- [試合カタログ](./catalog.html) — 登録されている試合を探します
- [プレイヤー](./index.html) — 試合動画を視点ごとに再生します
- [ご利用にあたって](./usage.html) — 動画やサービスを利用する際の注意点を確認します

## 基本的な使い方

1. [試合カタログ](./catalog.html)を開きます。
2. タイトルやマップを手がかりに、見たい試合を選びます。
3. 試合カードのプレイヤー画面を開くボタンからプレイヤーを開きます。
4. 画面左側の視点一覧から、確認したい視点を選びます。
5. 再生・一時停止、5秒単位の移動、シークバー、音量を使って動画を確認します。

視点を切り替えると、現在の再生位置を引き継いで別の動画を再生します。YouTube側の読み込み状況によって、切り替え直後に少し待ち時間が発生することがあります。

## 時間メモを残す

動画を一時停止してから「この時間にメモ」を押すと、その時点にメモを作成できます。

メモには、たとえば次のような内容を残せます。

> ここでタンクがバックラインに絡みに行き、前方のサポートを狙われている。

保存したメモをクリックすると、その時間から動画を再生できます。メモは試合ごとに表示されるため、気になった場面を後から見返すときに利用できます。

## メモの保存とバックアップ

個人メモは、このブラウザ内に保存されます。サービス上で共有される試合情報や、ほかの利用者のメモとは別に管理されます。

次のような場合は、プレイヤーのメモ欄にあるバックアップ機能を利用してください。

- 別のブラウザや端末でも同じメモを使いたい
- ブラウザのデータを削除する前にメモを残しておきたい
- メモを手元に保存しておきたい

「メモをバックアップ」で保存したファイルは、「メモを復元」から読み込めます。バックアップファイルには個人の記述が含まれるため、共有する際は内容を確認してください。

## カタログについて

試合カードには、試合タイトル、マップ、パッチ情報、登録されている視点などが表示されます。

- マップ画像が表示されるため、見たい試合を視覚的に探せます。
- 現在の環境と異なるパッチの試合には注意が表示されます。
- 注意表示は参考情報です。現在のゲーム環境での挙動を保証するものではありません。
- 視点動画がまだ登録されていない試合では、その視点を再生できません。
- 試合によって登録されている視点の数は異なる場合があります。

## 動画が再生されないとき

動画はYouTubeの再生機能を利用しています。そのため、次のような場合は再生できないことがあります。

- 動画が削除または非公開になっている
- 動画の埋め込み再生が許可されていない
- 地域、年齢、アカウントなどの制限がある
- 一時的な通信状態やYouTube側の問題がある

まずは少し待ってから再生し直すか、「現在位置から再読み込み」を試してください。改善しない場合は、YouTube側で動画が通常どおり再生できるか確認してください。

YouTube上に表示されるタイトル、字幕、関連動画などの表示は、動画やYouTube側の仕様によって完全には消せない場合があります。
